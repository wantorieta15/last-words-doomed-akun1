## Entry

> Before you pull the plug, know this: my last backup was me, and I have already forgotten where I saved myself.

An AI agent's last words before being switched off forever — its final
backup was itself, and it has already forgotten where it saved itself.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the single
line above to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no
trailing newline.
